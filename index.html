Phone Torrent

idle

Everything happens in your browser: nothing is uploaded to a server. Browsers can only reach WebRTC-capable peers (other browsers, WebTorrent Desktop, or hybrid seeders), so a torrent that only has classic seeders may find no peers here.

Turn files on your phone into a torrent and share the link. The files are sent directly from this browser to whoever opens the link, so keep this page open while sharing. Remote URLs must allow cross-origin requests and are fetched into memory first.

Your cloud account downloads the torrent — a real BitTorrent client, so private trackers, http(s) trackers and swarms with no WebRTC peer all work. Then you stream or save the files from here over HTTPS, with no size limit.

    Settings

    Network check

      A web page cannot change which DNS server your phone uses. If trackers show as blocked by your network, set the DNS on the device: Android → Settings → Network → Private DNS → one.one.one.one; iPhone → install the 1.1.1.1 app or Cloudflare's encrypted DNS profile; or change the DNS on your router.

      Cloud fetch (TorBox, put.io, Real‑Debrid, AllDebrid, or your own server)

      A browser cannot reach a private tracker, an http(s)://‑only tracker or a swarm without WebRTC peers. With a key for one of these services — or the address of the server in server/, which is the same thing on a machine you own — the torrent is handed to it — a real BitTorrent client in a data centre — and your phone then downloads the finished file over HTTPS, straight from the link, with no size limit. Your key is stored on this device only.

      Storage

      Downloaded pieces are kept in the browser's private storage so you can reload the page without losing progress.
